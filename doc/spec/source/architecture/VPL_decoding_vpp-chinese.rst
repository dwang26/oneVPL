=============================================
具有视频处理功能的视频解码
=============================================

:term:`DECODE_VPP` 相关函数将压缩比特流作为输入，
将其转换为原始帧并将视频处理过滤器应用于原始帧。
用户可以设置多个输出通道，其中每个通道包含一系列应用于解码帧的视频处理过滤器列表。

:term:`DECODE_VPP` 仅支持内部分配的内存分配模式。
